# Fresh paired category-union premise diagnostic, 24 October 2026

## Purpose and limits

The statement-evidence trial passed its numerical screen but failed independent
source review. It remains rejected. Two supported recoveries instead expose an
overstrict premise check: correct drafts can be discarded because a count over
several generic categories is treated as requiring every category to appear.

This diagnostic tests only a narrow opt-in `category-union` premise policy.
For an aggregate union count over generic item or event types, a mentioned
listed type can establish the subject. Explicit intersection or co-occurrence
conditions, such as attending both types on the same day, still require both.
Named people, places, specific objects and comparisons between distinct events
still require their identifying subjects. The treatment
does not equate merely related categories, change evidence, generate answers,
resolve dates or alter the original answer task.

This is post-hoc development on repeatedly inspected public data. It cannot
produce a new answer-accuracy score or authorize a public score update.
